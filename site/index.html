Uninstall programs, and what they leave behind.

Tracewipe runs a program's own uninstaller, waits for it to really finish, then finds the folders, registry keys, services and tasks it left. You review the list. Everything removed goes into a backup you can restore for seven days.

Download for Windows Source code

How a removal works

  1. CloseIf the program is running, Tracewipe offers to close it first.
  2. UninstallThe uninstaller runs in a job object. Tracewipe waits for it and every process it started.
  3. ScanTraces with strong evidence come checked. Weaker matches come unchecked, with the reason shown.
  4. RemoveFiles move into the backup folder. Registry keys and tasks are exported before they go.

What it finds

Programs come from the Uninstall registry keys, Microsoft Store packages, Scoop and Chocolatey. Several can be removed in one go, quietly where the installer allows it.

WhereWhat counts as a trace
Program Files, ProgramData, AppDataFolders named after the program or inside its publisher's folder
ProfileDot folders such as .rustup, Saved Games, Documents\My Games
Start menu and desktopShortcuts named after the program or pointing into its folder
RegistrySOFTWARE keys, Run entries, App Paths, file types, COM classes
SystemServices, firewall rules, scheduled tasks, PATH entries
CachesCrash reports, network tracing keys, MUICache and compatibility entries

Safety

Conservative matching

A folder or key must carry the program's exact name, or its content must point into the program's install folder.

Shared folders stay unchecked

A folder another installed program lives in is never checked by default, so Steam and its games are kept apart.

Seven day backup

Every removal can be restored from More, Backups. Locked files show which program holds them.

Protected locations

Windows, Program Files itself, the profile folders and the package managers' own folders are never offered.

Install tracing

More, Install with tracing runs an installer and records what it creates. Files come from the NTFS change journal, so nothing hooks into the installer. Registry keys come from comparing key names before and after. When the program is removed later, the trace makes the scan complete. Tracing needs administrator rights.

Command line

tracewipe --list
tracewipe --scan <name> [--deep]
tracewipe --orphans
tracewipe --uninstall <name> [--quiet] [--force] [--yes]

--scan and --orphans only list. --uninstall runs the uninstaller and scans, and with --yes removes the checked traces into a backup.

Build it yourself

git clone https://github.com/misutesu-desu/tracewipe
cd tracewipe
cargo build --release

Needs stable Rust and the Windows SDK. Run the program as administrator to remove traces under Program Files and HKLM.
